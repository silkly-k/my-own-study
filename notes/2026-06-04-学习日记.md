## 📚 今日知识点清单

### 1. 类型 vs 变量

- `int` 是**类型**（图纸），`x` 是**变量**（房子）
- `Button` 是**结构体类型**（自己画的图纸），`btn` 是**变量**（按图纸盖的房子）
- 一张图纸可以盖多间房子：`Button btn1, btn2, btn3;` 三个独立变量，类型相同

### 2. 指针 `int*`

- `int` 和 `int*` 是**两个不同的类型**
- `int* p` 存的是**地址**，不是整数本身
- `&x` 取地址，`*p` 解引用
- 用指针的理由：① 能改原变量 ② 不复制大数据

### 3. 结构体指针 `Button*`

- 和 `int*` 原理**完全一样**，只是指向的是自定义的 `Button` 结构体
- 用 `->` 访问成员（等价于 `(*ptr).member`）
- 嵌入式里几乎永远用指针传递结构体（省内存，4 字节 vs 30 字节）

### 4. `typedef` 起别名

```c
typedef struct _Button Button;  // struct _Button 太长，起别名 Button
```

### 5. 函数指针 `BtnCallback`

```c
typedef void (*BtnCallback)(Button*, void*);
```

- `BtnCallback` 是一个**类型名**，和 `int`、`char` 一样用
- 但这个类型存的是**函数地址**，不是数据
- `BtnCallback cb = my_func;` 把函数地址存进变量

### 6. 函数指针数组 `cb[7]`

- `BtnCallback cb[7]` = 7 个槽位的「电话本」
- 每个槽位存一个**函数地址**，对应一种事件
- cb[0]=按下回调，cb[3]=单击回调，cb[5]=长按开始回调...
- 未绑定的槽位 = NULL，调用前检查

### 7. 格式约束

- cb[7] 数组里**所有函数必须格式一致**：返回值 `void`，参数 `(Button*, void*)`
- 格式不匹配 → 编译报错

### 8. 回调两个参数的分工

| 参数 | 谁给的 | 含义 |
|------|--------|------|
| `Button* handle` | **库给你** | 哪个按键触发了事件 |
| `void* user_data` | **你之前传进去的** | 你的上下文数据（万能指针） |

---

## 🧠 核心理解

```
BtnCallback cb[7] 就是一个「电话本」：

  cb[0] → my_func_A 的地址   ← 按下事件 → 调用 my_func_A
  cb[1] → NULL               ← 松开事件 → 没注册，不调用
  cb[2] → NULL               ← 连按事件 → 没注册，不调用
  cb[3] → my_func_B 的地址   ← 单击事件 → 调用 my_func_B
  cb[4] → NULL               ← 双击事件 → 没注册，不调用
  cb[5] → my_func_C 的地址   ← 长按开始 → 调用 my_func_C
  cb[6] → NULL               ← 长按保持 → 没注册，不调用
```

**整个 MultiButton 库的核心就是：**

> 状态机判断发生了什么事件 → 找到 cb[] 对应槽位 → 如果槽位里有函数地址就调用它
